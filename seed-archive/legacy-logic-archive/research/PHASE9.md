# Phase 9 — ADS and 2007 cryogenics

This is a provenance-first discovery catalog, not a completed download of proprietary ADS libraries or copyrighted papers.

ADS = Agilent/Keysight Advanced Design System (assumption).

Historical focus: vendor ADS 2000–2009 design kits and 2007 hand-built cryocooler research. Modern Leiden LabVIEW code is a separate comparative reference.

## Archival gates
- Resolve final downloadable file URL manually from vendor page.
- Review terms and copyright before local preservation or redistribution.
- Record URL, publication year, retrieval time, SHA-256, format, and license evidence.
- Do not treat publication date as software creation date.
- Never run downloaded design kits or control software on live cryogenic hardware without independent safety review.
